BEHIND THE CURTAIN

Zero CORS, strict CSP, and bulletproof token relaying.

By running an internal HTTP loopback relay inside the Electron main process, JioTv Max maintains Chromium's strictest security policies while talking directly to Jio's live CDNs.

01

Loopback Stream Rewriting

Upstream HLS and DASH manifests are parsed and rewritten to point media chunks to ephemeral 127.0.0.1 URLs with session signatures.

02

Transparent Akamai Cookie Injection

Every chunk request forwards authentic Android client User-Agents and dynamic Akamai __hdnea__ tokens so CDN requests succeed without 403 blocks.

03

In-Memory DVR Segment Cache

A 64MB LRU cache retains recently watched segments, guaranteeing instant pause/resume and micro-rewinds even when upstream CDN tokens refresh.

src/main/media-relay.ts TypeScript 
// MediaRelay: Zero-CORS Loopback Stream Engine
export class MediaRelay {
  private server = createServer(async (req, res) => {
    const { pathname, searchParams } = new URL(req.url!, 'http://127.0.0.1')

    if (pathname === '/raw') {
      const rawUrl = searchParams.get('u')!
      const session = this.getSession(searchParams.get('s'))

      // Forward authentic Akamai cookies & player agent
      const upstream = await fetch(rawUrl, {
        headers: session.headers,
        signal: AbortSignal.timeout(12000)
      })

      // Rewrite nested manifests to keep session alive
      return this.relayStreamResponse(upstream, res)
    }
  })
}
