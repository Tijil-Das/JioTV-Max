## What's Changed in v1.0.3 🚀

### 🎨 Visual & UI Polish
- **Update Notification Button Styling**: Removed the glow effect from the update notification "Restart" button, aligning its style with the website's clean, flat solid-red button design (`#E11D2E` with subtle border and crisp hover states).

### 🧪 Update System Verification
- **Auto-Update Pipeline Validation**: This release serves as an active end-to-end test of the auto-update delivery system, verifying that existing client installs seamlessly receive the background delta update and differential `.blockmap` package without friction.

### ⚙️ Updater CLI & Tooling Polish
- **Modernized Terminal Dashboard**: Upgraded the release CLI (`updater-cli`) with solid Unicode block progress bars, resilient GitHub Actions live monitoring, and full terminal-width formatting to prevent status and timer text truncation.
