## What's Changed in v1.0.1 🚀

### ✨ New Features & Improvements
- **First-Run Onboarding Guide**: Added a clean onboarding modal to guide first-time viewers on connecting their Jio mobile plan and streaming live channels.
- **Streamlined Authentication**: Enforced clean initial sign-in modal sequencing on startup for unauthenticated sessions.
- **Safe Updater IPC Handlers**: Registered development IPC handlers for update status and checks, preventing renderer errors in non-packaged environments.
- **UI & Tagline Refinement**: Updated splash screen tagline to highlight desktop streaming powered by standard mobile plans.

### 🛠️ Developer & CI Improvements
- **Automated CI Quality Gates**: Added automated typechecks, full unit test suite verification (203 tests), and production bundle compilation checks to GitHub Actions.
- **Community Health**: Added `CONTRIBUTING.md`, Issue templates (Bug Report & Feature Request), and Pull Request templates.
- **Landing Site Release Resolver**: Upgraded website with automated OS detection and direct GitHub release resolution.
